# Super Store Sales Dashboard

A professional Power BI dashboard project focused on analyzing sales performance for a fictional superstore. This dashboard provides a clear view of sales trends, profitability, regional performance, category-wise contribution, and customer segments using interactive visuals and KPI cards.

## Overview

This report is designed to help business stakeholders understand:

- Total sales and profitability over time
- Regional and category performance
- Customer segment contribution
- Product-level sales trends
- Business performance by month and year

The dashboard is built in Power BI Desktop and packaged as a .pbix file for easy sharing and presentation.

## Business Objectives

The dashboard helps answer key business questions such as:

- Which regions contribute the most to revenue?
- Which product categories drive the highest sales and profit?
- How do sales trends change month to month?
- Which customer segments are performing best?
- Where are the biggest opportunities for growth?

## Dashboard Features

- Interactive slicers for region, category, and segment
- Sales and profit trend analysis by month
- KPI cards for total sales, profit, and quantity
- Top-performing regions and categories analysis
- Product-level performance insights
- User-friendly layout for executive reporting

## How to Use

1. Open the repository and download `Super Store Sales Dashboard.pbix`.
2. Open the file in Power BI Desktop.
3. Use the slicers and filters to explore the data by region, category, and segment.
4. Review KPI cards and visualizations for performance insights.
5. Refresh the dataset if connected to updated source data.

## Best Practices

- Use Power BI Desktop in the latest stable version for optimal compatibility.
- Refresh the report after any data updates.
- Keep filters and visuals aligned for presentation clarity.
- Validate data relationships before publishing to a shared workspace.
